Reduce an image to an exact file size

Many application portals — job sites, university admissions, exam registrations, visa and government forms — only accept photos and signatures below a certain size, such as 20KB, 50KB, 100KB or 200KB. Guessing the right quality setting can take many attempts. This tool does it for you: enter the maximum size in kilobytes and it automatically searches for the highest quality that stays under the limit. If the image still does not fit, it gently reduces the dimensions too.

How to compress a photo to 100KB

  1. Add your photo using the box above.
  2. The Target file size field is already set to 100. Change it to 50, 200 or any other value you need.
  3. Wait a moment while the best quality is calculated, then press Download.
Tip: always check the required dimensions too. Many forms ask for both a size limit (e.g. under 100KB) and specific pixel dimensions (e.g. 600×600). Enter the width and height in the resize fields first, then set the target size.

Which format should I use?

JPEG is selected by default because almost every form accepts it. WEBP produces even smaller files but is not accepted everywhere. PNG cannot be compressed to a target size because it is lossless, so PNG images are automatically saved as JPEG when a target size is set.

Frequently asked questions

Can I compress an image to 50KB or 20KB?

Yes. Type any number into the Target file size field, for example 50 or 20.

Why did the dimensions of my image change?

If the image cannot reach the target size at a reasonable quality, the tool reduces the dimensions slightly so the photo stays clear instead of becoming blocky.

Is my document uploaded to a server?

No. All processing happens on your device, which makes it safe for ID photos and personal documents.
