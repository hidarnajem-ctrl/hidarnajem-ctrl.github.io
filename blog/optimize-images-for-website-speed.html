How to Optimize Images for a Faster Website

By the Teknawy team · November 13, 2026 · 8 min read

Images usually make up the largest share of a web page's weight. Optimizing them is one of the quickest ways to make a site faster, reduce bounce rates and improve Google's Core Web Vitals. Here is a practical checklist you can follow for every image you publish.

Why image optimization matters

Google measures real-user experience with Core Web Vitals. One of them, Largest Contentful Paint (LCP), measures how long it takes for the biggest visible element to appear — and on most pages that element is an image. A 3 MB hero photo on a mobile connection can take several seconds to arrive, while a well-optimized 150 KB version appears almost instantly.

1. Serve images at the right dimensions

Never rely on CSS to shrink a huge image. If an image is displayed at 800 pixels wide, export it at about 800–1600 pixels (the larger size covers high-density “retina” screens). Use the resize tool to set a maximum width before uploading.

2. Use modern formats

WEBP is supported by all modern browsers and is usually 25–35% smaller than JPEG at the same quality. If your platform supports it, serve WEBP for photos and graphics alike.

3. Compress sensibly

A quality between 75% and 85% is the sweet spot for most photographs. Combined with resizing and WEBP, this commonly reduces images by 80–90% compared with the camera original.

4. Always set width and height

Add width and height attributes to your <img> tags. The browser can then reserve the correct space before the image loads, preventing the page from jumping around. This improves another Core Web Vital, Cumulative Layout Shift (CLS).

5. Lazy-load images below the fold

Add loading="lazy" to images that are not visible when the page first opens. The browser will download them only when the visitor scrolls near them. Do not lazy-load the main hero image — it should load as early as possible.

6. Use responsive images

With the srcset and sizes attributes you can offer several sizes of the same image and let the browser pick the best one for each screen. Phones download a small version; large desktop screens get a larger one.

7. Write descriptive alt text

Alt text is read by screen readers and helps search engines understand your images. Describe what the image shows in a short, natural sentence, for example “Red running shoes on a wooden floor” instead of “IMG_2041”.

8. Use meaningful file names

Rename files before uploading: red-running-shoes.webp is more helpful than DSC00231.jpg for both visitors and image search.

Quick checklist

  • Resized to the display size (max ~2× for retina)
  • Saved as WEBP (or JPEG for compatibility)
  • Quality around 75–85%
  • Width and height attributes set
  • Lazy loading for below-the-fold images
  • Descriptive alt text and file name
